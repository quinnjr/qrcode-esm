Getting Started

Installation

Install with your preferred package manager:

Shell
# npm
npm install @quinnjr/qrcode-esm

# pnpm
pnpm add @quinnjr/qrcode-esm

# yarn
yarn add @quinnjr/qrcode-esm

Quick Start

The library automatically provides the right exports for your environment. Node.js gets file/buffer support; browsers get canvas support.

Node.js
import { toString } from '@quinnjr/qrcode-esm';

const qr = await toString('https://example.com');
console.log(qr);
Browser
import { toCanvas } from '@quinnjr/qrcode-esm';

const canvas = await toCanvas('https://example.com');
document.body.appendChild(canvas);

Usage Examples

Node.js

TypeScript
import { toString, toDataURL, toBuffer, toFile } from '@quinnjr/qrcode-esm';

// Render to UTF-8 string (for terminals)
const str = await toString('https://example.com');
console.log(str);

// Render to PNG data URL
const url = await toDataURL('https://example.com');

// Render to PNG buffer
const buf = await toBuffer('https://example.com');

// Write to file (format inferred from extension)
await toFile('qr.png', 'https://example.com');
await toFile('qr.svg', 'https://example.com');
await toFile('qr.txt', 'https://example.com');

Browser

TypeScript
import { toString, toCanvas, toDataURL } from '@quinnjr/qrcode-esm';

// Render to SVG string (default in browser)
const svg = await toString('https://example.com');

// Render to a new canvas element
const canvas = await toCanvas('https://example.com');
document.body.appendChild(canvas);

// Render to an existing canvas element
const el = document.getElementById('canvas') as HTMLCanvasElement;
await toCanvas(el, 'https://example.com');

// Render to data URL via canvas
const url = await toDataURL('https://example.com');

With Options

TypeScript
import { toString } from '@quinnjr/qrcode-esm';

const qr = await toString('https://example.com', {
  errorCorrectionLevel: 'H',
  type: 'svg',
  margin: 2,
  width: 300,
  color: {
    dark: '#1a1a2e',
    light: '#ffffff',
  },
});

API Reference

All rendering functions accept a text string (or array of segments) and an optional RendererOptions object. All return Promises except create().

create(text, options?)

Node Browser

Creates QR code data without rendering. Returns a QRData object containing the module matrix, version, error correction level, mask pattern, and segments. Useful when you need raw QR data for custom rendering.

Parameters

NameTypeDescription
textQRInputText string or array of segments to encode
optionsQRCodeOptionsOptional QR generation options

Returns

QRData — Object with modules, version, errorCorrectionLevel, maskPattern, and segments.

Example
import { create } from '@quinnjr/qrcode-esm';

const qr = create('Hello World', {
  errorCorrectionLevel: 'H',
});

console.log(qr.version);              // e.g. 2
console.log(qr.modules.size);          // e.g. 25 (21 + 4*version)
console.log(qr.errorCorrectionLevel);  // { bit: 2 }
console.log(qr.maskPattern);           // 0-7

toString(text, options?)

Node Browser

Renders a QR code as a string. The output format depends on the type option and the environment.

typeNode defaultBrowser defaultDescription
'utf8'YesUTF-8 block characters (▀▄█)
'terminal'ANSI-colored terminal output
'svg'YesSVG XML markup

Parameters

NameTypeDescription
textQRInputText string or array of segments to encode
optionsRendererOptionsOptional rendering options

Returns

Promise<string>

Example
// SVG output
const svg = await toString('https://example.com', { type: 'svg' });

// Terminal output (compact)
const term = await toString('https://example.com', {
  type: 'terminal',
  small: true,
});

toDataURL(text, options?)

Node Browser

Renders a QR code as a data URL string.

  • Node: Generates a PNG, SVG, or UTF-8 data URL depending on the type option.
  • Browser: Renders to an offscreen canvas and calls canvas.toDataURL().

Parameters

NameTypeDescription
textQRInputText string or array of segments to encode
optionsRendererOptionsOptional rendering options

Returns

Promise<string> — Data URL (e.g. data:image/png;base64,...)

Example
const url = await toDataURL('https://example.com', {
  width: 200,
  margin: 2,
  color: {
    dark: '#000000',
    light: '#ffffff',
  },
});

// Use as image source
const img = document.createElement('img');
img.src = url;

toCanvas(text, options?)

toCanvas(canvas, text, options?)

Browser

Renders a QR code onto an HTMLCanvasElement. If no canvas is provided, a new one is created and returned. If an existing canvas element is provided, the QR code is drawn onto it.

Parameters

NameTypeDescription
canvasHTMLCanvasElement(Optional) Existing canvas element to render onto

optionsRendererOptionsOptional rendering options

Example

Options

All rendering functions accept an optional RendererOptions object that controls both QR code generation and rendering output.

QR Code Options

OptionTypeDefaultDescription
version number Auto QR version (1–40). Determines the size of the QR code. Automatically selected if omitted based on the input data length and error correction level.
errorCorrectionLevel string 'M' Error correction level. Accepts 'L', 'M', 'Q', 'H' or their full names 'low', 'medium', 'quartile', 'high' (case-insensitive).
maskPattern number Auto Mask pattern (0–7). Automatically selected for optimal readability if omitted.
toSJISFunc function — Custom function for Shift JIS encoding of Kanji characters.

Renderer Options

OptionTypeDefaultDescription
type string Varies Output format: 'png', 'svg', 'utf8', 'terminal', or 'image/png'. Default depends on the function and environment.
margin number 4 Size of the quiet zone around the QR code, in modules. The QR spec recommends at least 4.
scale number 4 Scale factor — the number of pixels per module.
width number — Output width in pixels. Overrides scale when set. Must be ≥ 21.
color.dark string '#000000ff' Color of the dark modules. Hex string (3, 4, 6, or 8 characters).
color.light string '#ffffffff' Color of the light modules and background. Hex string (3, 4, 6, or 8 characters).
small boolean false Use compact rendering for terminal output (half-height characters).
inverse boolean false Invert the dark and light colors.
rendererOpts object {} Additional format-specific options (e.g. canvas quality).

Color Format

Color values support multiple hex formats:

FormatExampleExpansion
3-character#abc#aabbcc (fully opaque)
4-character#abcd#aabbccdd (with alpha)
6-character#rrggbbFully opaque
8-character#rrggbbaaWith alpha channel

Error Correction

QR codes use Reed-Solomon error correction to remain scannable even when partially damaged or obscured. Higher levels increase reliability at the cost of larger QR codes.

LevelAliasesRecovery CapacityUse Case
'L' 'low' ~7% Maximum data density. Use when QR code will be displayed cleanly (screens, print).
'M' 'medium' ~15% Default. Good balance of size and reliability for most use cases.
'Q' 'quartile' ~25% When QR codes may be partially obscured (e.g. stickers, posters).
'H' 'high' ~30% Maximum reliability. Required when embedding logos over the QR code.
Example
await toString('https://example.com', {
  errorCorrectionLevel: 'H',   // maximum error correction
});

// Full name also accepted (case-insensitive)
await toString('https://example.com', {
  errorCorrectionLevel: 'quartile',
});

Encoding Modes

QR codes support multiple encoding modes. The library automatically selects the optimal mode (or combination of modes) to minimize the size of the generated QR code. You can also specify modes explicitly via segments.

ModeCharactersEfficiency
Numeric 0–9 Most compact. 3 digits per 10 bits.
Alphanumeric 0–9, A–Z, space, $ % * + - . / : 2 characters per 11 bits.
Byte Any UTF-8 byte 1 byte per 8 bits. Used for general text.
Kanji Shift JIS kanji characters 1 character per 13 bits. Requires toSJISFunc.

When a string contains mixed character types, the library uses Dijkstra's algorithm to find the optimal combination of modes that produces the smallest QR code.

Segments

For precise control over encoding, pass an array of segments instead of a plain string. Each segment specifies the data and its encoding mode.

Mixed-Mode Encoding
import { toString } from '@quinnjr/qrcode-esm';

const qr = await toString([
  { data: '1234567890', mode: 'numeric' },
  { data: 'ABCDEF', mode: 'alphanumeric' },
  { data: 'hello world', mode: 'byte' },
]);

Available mode values: 'numeric', 'alphanumeric', 'byte', 'kanji'. You can also pass plain strings in the array, which will be auto-detected:

Mixed Array
await toString([
  'auto-detected string',
  { data: '1234', mode: 'numeric' },
]);

Output Formats

The library provides multiple output formats optimized for different environments.

PNG

Node

Raster image format. Generated using a built-in PNG encoder with no native dependencies.

Available via: toFile(), toBuffer(), toDataURL()

SVG

Node Browser

Scalable vector format. Clean XML output, ideal for web use. Default format for toString() in the browser.

Available via: toString(), toFile(), toBuffer(), toDataURL()

UTF-8

Node Browser

Text representation using Unicode block characters. Default format for toString() in Node.js.

Available via: toString(), toFile(), toBuffer()

Terminal

Node

ANSI-colored output for terminal display. Use small: true for compact half-block rendering.

Available via: toString()

Canvas

Browser

Renders directly onto an HTML Canvas element. Can create a new canvas or draw onto an existing one.

Available via: toCanvas(), toDataURL()

TypeScript Types

All public types are exported and available for import. The library provides separate type declarations for Node.js and browser environments.

Importing Types
import type {
  QRData,
  QRInput,
  QRCodeOptions,
  RendererOptions,
  Segment,
  Mode,
  ErrorCorrectionLevel,
} from '@quinnjr/qrcode-esm';

Key Types

QRData
interface QRData {
  modules: BitMatrix;             // 2D module grid
  version: number;                // 1-40
  errorCorrectionLevel: ErrorCorrectionLevel;
  maskPattern: number;            // 0-7
  segments: Segment[];
}
QRInput
type QRInput = string | (string | {
  data: string;
  mode?: Mode | string;
})[];
RendererOptions
interface RendererOptions extends QRCodeOptions {
  margin?: number;                // quiet zone (default: 4)
  scale?: number;                 // pixels per module (default: 4)
  width?: number;                 // output width in px
  color?: {
    dark?: string;               // hex color (default: '#000000ff')
    light?: string;              // hex color (default: '#ffffffff')
  };
  type?: string;                  // output format
  small?: boolean;                // compact terminal output
  inverse?: boolean;              // invert colors
  rendererOpts?: Record<string, unknown>;
}
QRCodeOptions
interface QRCodeOptions {
  version?: number;               // 1-40
  errorCorrectionLevel?: ErrorCorrectionLevelInput;
  maskPattern?: number;           // 0-7
  toSJISFunc?: (kanji: string) => number;
}
ErrorCorrectionLevelInput
type ErrorCorrectionLevelInput =
  | ErrorCorrectionLevel
  | 'L' | 'M' | 'Q' | 'H'
  | 'low' | 'medium' | 'quartile' | 'high'
  | 'l' | 'm' | 'q' | 'h';

QR Version Sizes

The QR version determines the number of modules (pixels) in the code. The formula is: size = 17 + 4 × version.
